# Wire capture (Rust migration — Phase 1)

Records exactly what the existing Python service sends to and receives from each
real instrument, so the Rust device-definition interpreter can be built and
tested against ground truth. See `ai_context/RUST_TAURI_MIGRATION_PLAN.md`.

**No repository source is modified.** `tracer.py` monkeypatches pyserial and the
USBTMC transport's `os` calls at runtime inside the traced process only.

## Files

| File | Purpose |
|---|---|
| `tracer.py` | Runtime patches; logs every tx/rx byte, DTR/RTS, open/close, call durations and the driver method on the stack |
| `run_traced_service.py` | Starts the normal FastAPI service (port 57990, UI off, isolated data dir) with the tracer installed |
| `exercise.py` | Drives the service: passive `/ws/registry` capture, every GET query per device/class/channel, optional opt-in setters |
| `summarize.py` | JSONL → `<dev>.transcript.txt` + `<dev>.stats.json` (reply variants, sizes, timing, framing end reason) |
| `setters.example.yaml` | Template for an explicit, safe setter scenario |
| `sim_tenma.py`, `selftest.sh` | Simulated TENMA on a pty pair; end-to-end self-test of the tooling (no hardware) |

## Capturing real instruments

1. Stop the normal service (`start.sh` / Electron) — instrument ports must not be shared.
   The runner refuses to start if another process holds a configured port.
2. Terminal A (from repo root):
   ```bash
   python3 scripts/wire_capture/run_traced_service.py            # uses ~/.benchmesh/config.yaml
   ```
3. Terminal B:
   ```bash
   python3 scripts/wire_capture/exercise.py --passive 30 --rounds 3
   # optional, only with values that are safe for what is connected:
   python3 scripts/wire_capture/exercise.py --passive 0 --rounds 0 --setters my_setters.yaml
   ```
4. Ctrl-C terminal A, then:
   ```bash
   python3 scripts/wire_capture/summarize.py                    # latest session
   ```

Sessions land in `captures/<timestamp>/`: `<device>.jsonl` (raw wire),
`api.jsonl` (API calls + parsed results + registry snapshots), `session.json`
(config, manifests, env, git rev), plus the summarizer outputs. Captures are the
golden transcripts for Rust replay tests. Before committing, compress the raw
logs (`gzip -9 captures/<session>/*.jsonl`); commit `*.jsonl.gz`, `session.json`
and `*.stats.json`. Transcripts are regenerated by `summarize.py` (it reads `.gz`).

`query_screenshot` is excluded by default: the Python GET dispatch passes the
channel number as `save_path`, which makes the DGE driver close the server's stdout.

## Self-test (no hardware)

```bash
scripts/wire_capture/selftest.sh        # needs socat; uses port 57991; cleans up after itself
```
`--sim-pty` (used only by the self-test) tolerates ENOTTY from DTR/RTS, which
pseudo-terminals do not support. Never use it with real instruments.
